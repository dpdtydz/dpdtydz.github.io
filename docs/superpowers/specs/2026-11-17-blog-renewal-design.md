작성일: 2026-11-17

참고(구조만): https://dowha.kim/ — 비주얼은 차별화, 허브+타임라인 구조만 참고

## 1. 배경 / 문제점 (AS-IS)

| # | 피드백 | 원인 위치 |
|---|--------|-----------|
| 1 | 포트폴리오 말투가 "AI 같다" | 주로 `aboutme.md` (BREAK THE EARTH, 이모지 과다). `index.html` 본문은 양호 |
| 2 | 포트폴리오 카드의 "Read More"가 어색 | `index.html` 성과 카드 — 영어 라벨, 어색한 문구 |
| 3 | 카드 링크가 영어·색상 제각각이라 "버튼이 다 다른 위치에 달린 느낌" | 카드마다 위치·스타일 불일치 |
| 4 | 과거 TIL/WIL에 "오래전 정리 안 된 포인트" 잔존 | `_posts/TILs/` 2020~2025 TIL 약 60개 + 날짜트릭(1999-01-01 등) |
| 5 | My resume가 옛날 데이터 | `_posts/TILs/1999-01-02-TIL.md`, `2022-01-03-resumeconfrom.md` |
| 6 | Jekyll 유지하며 기술적으로 리뉴얼 | Beautiful Jekyll 테마 유지 전제 |
| 7 | 과거 블로그 포스트 리터치 필요 | `_posts/*.md` 트러블슈팅 글 11개 |
| 8 | 미사용 `.shop` 도메인 (`tildp.shop`) | `_config.yml` `url-pretty` |

현재 구조: 포트폴리오(`index.html`)와 블로그(Beautiful Jekyll)가 색상만 통일됐을 뿐
두 개의 다른 사이트처럼 붙어 있음. nav는 "포트폴리오 / About Me / Resources(TIL·WIL·Resume 드롭다운)".

## 2. 방향 (TO-BE) — 확정된 결정

- **하이브리드**: 담담한 개인 허브 + 당당한 포트폴리오/이력서
- **홈 = 새 랜딩(허브) 페이지** (기존 포트폴리오 본문은 Work로 분리)
- **카드 링크 → `>` 화살표만** (영어 "Read More" 제거, 텍스트 없이 아이콘 하나)
- **About/이력서 = 아는 정보로 초안 먼저**, 사용자가 틀린 곳만 수정
- **과거 TIL = 숨기기 + 선별 아카이브** (파일은 git 보관, 사이트 비노출)
- **기존 포스트 11개 = 말투·가독성만 정리** (기술 내용 유지)
- **`.shop` 도메인 = 설정에서 제거만** (`github.io` 기본 주소 사용)
- **비주얼은 유지**: 다크 배경 + 보라 액센트(`#6c63ff`/`#a78bfa`) + Space Grotesk.
  dowha(라이트/세리프)와 확실히 차별화 — 구조만 참고

## 3. 네비게이션 재구성

```
[이호상]   Work   Writing   About        ← 미니멀 3개 (+로고=홈)
```

| 메뉴 | 내용 | 비고 |
|------|------|------|
| 홈(/) | 담담한 허브(새 랜딩) | 신규 |
| Work | 기존 포트폴리오 본문(성과·경력·무기고) | `index.html` → `work.html`로 이동, 다듬기 |
| Writing | 기술 블로그 글 11개(피드+태그) | 기존 Jekyll 피드 유지 |
| About | `aboutme.md` 전면 리라이트 | 말투 교체 |
| ~~Resources 드롭다운~~ | **삭제** | TIL/WIL/Resume 비노출 |

이력서는 메뉴에서 빼고 About 하단에 경력 요약 포함(필요 시 "이력서 보기 →" 링크 자리만 마련).

## 4. 홈(/) 랜딩 페이지

dowha식 담담한 단일 컬럼, 당신의 다크+보라 톤 유지. 타이핑 애니메이션·과한 그라데이션 없음.

```
─────────────────────────────
 이호상                          ← 이름(크게)
 서버와 데이터를 다루는 백엔드 개발자입니다.   ← 모토(확정: 안 B)

 짧은 자기소개 2~3문장 (담담한 1인칭)

─ 요즘 하는 일 ──────────────  → Work
   (1~2문장 + "자세히 →")

─ 최근에 쓴 글 ─────────────   → Writing
   · 글 제목 →
   · 글 제목 →                  (Jekyll site.posts 최근 3개 자동)

─ 커리어 ──────────────────   → About
   2023.08  아이스크림에듀
   2022.08  아이스크림키즈        (타임라인 요약, 더보기)
─────────────────────────────
```

- 모토(확정): **"서버와 데이터를 다루는 백엔드 개발자입니다."**
  (한 줄로 분리해 추후 교체 쉽게)
- 섹션 진입은 `→`/`>` 화살표 하나로 통일(카드 피드백과 동일 원칙).

## 7. 과거 TIL/WIL/Resume 처리

- `_posts/TILs/`의 날짜트릭 포스트(`1999-01-01`, `1999-01-02`, `2021-06-03` 등)와
  2020~2025 잡다한 TIL을 **사이트에서 비노출**.
- 비노출 방식: Jekyll collection/exclude 또는 `published: false` 등 빌드 산출물에서 제외.
  **파일은 git에 보존(삭제 아님).**
- 쓸만한 것만 선별해 "기록/아카이브"로 정리(선별은 최소 범위, 필요 시 후속).
- nav의 Resources 드롭다운 삭제.

## 10. 기술 구조 (Jekyll 유지)

| 항목 | 방식 |
|------|------|
| 홈 | `index.html`을 새 랜딩으로 교체 |

## 11. 작업 순서

1. `.shop` 도메인 참조 제거 + nav 재구성(Work/Writing/About, Resources 삭제)
2. 새 홈 랜딩 페이지 작성(`index.html` 교체, 최근 글 자동)
3. 기존 포트폴리오 → `work.html` 이동 + 카드 `>` 화살표
4. `aboutme.md` 담담하게 리라이트(초안 → 사용자 확인)
5. TIL/WIL/Resume 날짜트릭 포스트 비노출 + 선별 아카이브
6. 블로그 포스트 11개 말투·가독성 정리
7. 로컬 빌드 확인 → 커밋
